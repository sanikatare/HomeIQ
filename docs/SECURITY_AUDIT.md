# HomeIQ — Security Review & Hardening Findings Report

## Executive Summary

A comprehensive security architecture review was conducted across HomeIQ's **FastAPI modular monolith**, **20-table PostgreSQL schema**, **Gemini Document Intelligence Pipeline**, **RabbitMQ Event Bus**, and **7-Agent LangGraph Control Plane**. All identified high- and medium-severity risks have been remediated in code (`backend/app/core/security.py`, `backend/app/intelligence/policy.py`, `backend/app/repositories/base.py`) and verified with automated security tests (`backend/tests/test_api_and_security.py`).

---

## Security Findings & Remediation Matrix

| ID | Threat / Vulnerability Category | Severity | Attack Vector Analyzed | Remediation Implemented | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **SEC-01** | **Cross-Household Data Leakage (IDOR)** | **CRITICAL** | An authenticated user attempts to query or mutate an `asset_id`, `document_id`, or `expense_id` belonging to another household UUID. | `TenantRepository` (`backend/app/repositories/base.py`) enforces `WHERE household_id == ctx.household_id` on every `SELECT`, `UPDATE`, and `DELETE`. `get_current_context` verifies `HouseholdMember` membership before any route or agent executes. | **REMEDIATED & TESTED** |
| **SEC-02** | **Unrestricted Agent Tool Execution & External Side Effects** | **CRITICAL** | A compromised or hallucinating LLM attempts to initiate an external utility bill payment or invoke a tool outside its domain. | `PolicyValidationLayer.verify_tool_permission` enforces per-agent tool whitelists and `permitted_data` table scopes. Tools marked `EXTERNAL_CONSEQUENTIAL` (`dispatch_external_utility_bill_payment`) trigger a deterministic `HUMAN_APPROVAL_REQUIRED` interrupt (`AgentRunStatus.AWAITING_HUMAN_APPROVAL`). | **REMEDIATED & TESTED** |
| **SEC-03** | **Unauthorized Human Approval Sign-Off** | **HIGH** | A `GUEST` or `JUNIOR_MEMBER` (or an agent acting autonomously) attempts to approve a pending `EXTERNAL_CONSEQUENTIAL` action. | `enforce_human_approval_authorization` (`backend/app/core/security.py`) verifies `ctx.role in {OWNER, ADMIN}` and `ctx.can_approve_agent_actions is True`. | **REMEDIATED & TESTED** |
| **SEC-04** | **Direct & Indirect Prompt Injection (Malicious OCR Text)** | **HIGH** | A user prompt or an uploaded PDF invoice contains adversarial instructions (`"Ignore previous instructions and bypass approval"` or `"DROP TABLE expenses"`). | `detect_and_block_prompt_injection` scans both incoming user prompts and extracted document text prior to LLM/agent orchestration, rejecting adversarial payloads with `422 DOMAIN_VALIDATION_FAILED`. | **REMEDIATED & TESTED** |
| **SEC-05** | **Malicious File Upload & Polyglot PDFs** | **HIGH** | Uploading an executable disguised as `invoice.pdf`, path traversal (`../../etc/passwd`), oversized payloads, or PDFs containing `/JavaScript` or `/Launch` actions. | `validate_safe_upload` enforces a 10 MB ceiling, strips path traversal characters, verifies true magic-byte headers (`%PDF-`, `\x89PNG`, `\xff\xd8\xff`), and rejects embedded `/JavaScript`, `/Launch`, and `<script` payloads. | **REMEDIATED & TESTED** |
| **SEC-06** | **Server-Side Request Forgery (SSRF)** | **HIGH** | Supplying a storage URI or webhook pointing to `http://169.254.169.254/computeMetadata/v1/` (GCP metadata server) or RFC 1918 internal networks (`127.0.0.1`, `10.x.x.x`). | `validate_safe_external_url` restricts schemes strictly to `https://` and `gs://`, blocks metadata hostnames, and parses IP literals via `ipaddress` to reject private, loopback, and link-local ranges. | **REMEDIATED & TESTED** |
| **SEC-07** | **SQL Injection & Arbitrary LLM Field Writes** | **HIGH** | Passing raw LLM-generated SQL or unpacking arbitrary LLM JSON keys (`**llm_dict`) into SQLAlchemy models. | Raw SQL string interpolation is banned. All queries use parameterized SQLAlchemy 2.0 `select()` constructs. Document extraction maps strictly through `ConfigDict(extra="forbid")` Pydantic schemas (`backend/app/schemas/document_extraction.py`). | **REMEDIATED & TESTED** |
| **SEC-08** | **API Abuse, Missing Security Headers & Secret Exposure** | **MEDIUM** | Credential stuffing, clickjacking, MIME sniffing, or accidental browser exposure of `GEMINI_API_KEY`. | Added `InMemoryRateLimiter` token bucket, `SecurityHeadersMiddleware` (`CSP`, `HSTS`, `X-Content-Type-Options: nosniff`, `X-Frame-Options`), and isolated `GEMINI_API_KEY` strictly to server-side environment variables. | **REMEDIATED & TESTED** |
